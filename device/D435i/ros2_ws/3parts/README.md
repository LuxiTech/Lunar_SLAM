# D435i SDK dependencies

The Intel RealSense SDK source tree is not committed in this branch.

Download it from the official upstream repository when needed:

```text
Intel RealSense SDK / librealsense:
https://github.com/IntelRealSense/librealsense.git
```

Suggested local path:

```text
device/D435i/ros2_ws/3parts/librealsense
```

Do not commit the downloaded SDK source tree.
