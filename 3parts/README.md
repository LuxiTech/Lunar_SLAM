# Third-party dependencies

This directory does not vendor third-party SDK/source trees in this branch.

Download the required upstream projects when building from source:

```text
RTAB-Map:
https://github.com/introlab/rtabmap.git

RTAB-Map ROS:
https://github.com/introlab/rtabmap_ros.git

OctoMap:
https://github.com/OctoMap/octomap.git
```

Keep downloaded upstream code outside this repository or add it locally under
`3parts/` without committing it.
