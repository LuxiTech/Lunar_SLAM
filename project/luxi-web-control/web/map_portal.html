HTTP API 外部系统接入说明 展开

接口与本网页同源。外部页面将下面地址前缀替换为机器人 IP 即可调用。

GET /api/capabilities查询网页支持的全部 API 操作
GET /api/maps按 map 分组的地图清单、文件和下载链接
POST /api/maps/map037/preview默认加载过滤版；也可传 JSON：{"filtered": false}
GET /api/maps/map037/preview/cloud读取该 map 已加载的彩色点云
GET /api/maps/map037/preview/terrain读取可通行面、障碍和代价值
GET /api/maps/map037/preview/costmap独立读取可通行点和 0～1 代价值
GET /api/maps/map037/preview/obstacles独立读取静态障碍物点
GET /api/maps/map037/download/cloud流式下载 PLY，支持 Range 续传
GET /api/preview/rgb拉取当前相机 RGB 图像
POST /api/camera/start启动相机，JSON：{"profile":"d455"}
POST /api/robot/control机器人控制开关，JSON：{"active":true}
POST /api/imu/calibrate机器人开启并静止后，开始 IMU 水平校准
POST /api/navigation/localize启动定位，JSON：{"map_id":"map037"}
POST /api/navigation/goal发送目标，yaw 使用弧度：{"x":1.2,"y":0.8,"z":0,"yaw":1.57}
POST /api/navigation/start开始执行已规划路径
POST /api/navigation/halt停止任务并清空旧路径，继续保持定位
POST /api/cmd_velWASD/轮盘速度控制，支持 linear_x、angular_z 和 client_id
POST /api/stop释放网页控制租约并立即停车
POST /api/system/restart安全关闭全部服务后重新拉起，JSON：{"confirm":"restart_all_services"}
